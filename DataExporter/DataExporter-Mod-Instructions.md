# SMAPI Data Exporter Mod

This will export ALL Stardew Valley game data to JSON files.

## What You Need to Do

1. Create this folder structure in your Stardew Valley directory:
   ```
   Mods/DataExporter/
   ```

2. Create two files (I'll provide the code):
   - `manifest.json` - Mod metadata
   - `ModEntry.cs` - Export logic

3. Run the game once
4. Data files will be created in `Mods/DataExporter/exported/`
