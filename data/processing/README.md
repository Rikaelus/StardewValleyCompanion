# Processing Directory

This directory contains **intermediate/temporary files** generated during the data processing pipeline.

## Purpose

Files here are created by processing scripts for:
- Debugging and verification
- Intermediate data transformations
- Step-by-step pipeline outputs

## Git Status

⚠️ **This entire directory is gitignored** - these files are temporary artifacts of the processing pipeline.

## Current Files

### extracted-locations.json
- **Generated by**: `scripts/extract-fish-locations.cjs`
- **Purpose**: Maps fish gameIds to their locations for verification
- **Used by**: Nothing (debugging/verification only)
- **Format**: `{ "locations": { "gameId": ["Location Name", ...], ... } }`

## Data Flow

```
game-exports/     Processing Scripts      processing/           processed/
  Fish.json    →  extract-fish-locations  →  extracted-locations.json
  Locations.json                              (intermediate)
                                                ↓
                  process-game-data       →  fish.json
                                              (final output)
```

## Adding New Intermediate Files

If a processing script needs to output intermediate files for debugging:

1. Write to `data/processing/your-file.json`
2. Document it in this README
3. No need to update .gitignore (whole directory is ignored)

## Cleanup

You can safely delete files in this directory - they will be regenerated when scripts run.

```bash
# Clean all intermediate files
rm -rf data/processing/*
```
